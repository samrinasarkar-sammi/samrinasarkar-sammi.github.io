Data preparation and exploratory analysis, late-delivery classification, network analysis, demand forecasting and a Power BI dashboard.

Revisiting published student-feedback research with a transformer-based extension.

5-fold cross-validation

The question

Does a pretrained Bengali transformer improve on earlier approaches to classifying student feedback?

Research and extension

I co-authored the original published work comparing machine learning, deep learning and hybrid methods. The repository extends that work with BanglaBERT fine-tuning and five-fold stratified cross-validation.

05NLP + MACHINE LEARNING

Bengali Product
Review Sentiment

A small, self-collected review dataset for comparing text classification approaches.

7 classifiers compared

Python · scikit-learn · TF-IDF

Read case study

What I built

Collected 300 Bengali e-commerce reviews, prepared Unicode text, generated TF-IDF unigram, bigram and trigram features, and compared seven ML classifiers.

Evaluation

Compared accuracy, precision, recall and F1. Perfect scores on a test set of only 30 examples should not be interpreted as strong evidence of generalization. This project used a single split rather than cross-validation.
